Privacy policy

Content Clips · last updated 3 November 2026

Content Clips is a single-user tool, operated by one individual, that uploads that person's own video clips to that person's own YouTube channel. It has no other users. This policy describes what it does with data, which is deliberately very little.

Who operates it

Content Clips is operated by an individual and can be reached at bonusyunus64@gmail.com.

Information it accesses

Content Clips requests the following Google account permissions, and only for the account of its operator:

  • youtube.upload — to upload video files to the operator's own YouTube channel and set each video's title, description and thumbnail.
  • youtube.readonly — to read back the status of a video it has just uploaded, so it can confirm the upload succeeded and that the thumbnail was applied.

It does not read, collect or process any other Google account data. It does not access contacts, email, calendars, files other than the video clips its operator places in a folder for it, or any data belonging to any other person.

How that access is used

Solely to publish the operator's own videos to the operator's own channel. The access is not used for advertising, analytics, profiling, training machine learning models, or any purpose unrelated to uploading those videos.

Storage

Content Clips stores one credential: an OAuth refresh token for the operator's Google account. It is held as an encrypted secret in the private GitHub repository that runs the tool, is never written to logs, and is visible only to the operator.

The tool also keeps a record of which clips it has published and when, so it does not publish the same clip twice. That record contains filenames, timestamps and YouTube video IDs. It contains no personal information about anyone.

Sharing

No data is shared with anyone. Nothing is sold, rented, or transferred to third parties. The only external services involved are Google's own APIs, which receive the video being uploaded, and GitHub, which stores the code and the encrypted credential.

Limited use

Content Clips' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The stored credential can be revoked at any time by its operator at myaccount.google.com/permissions, which immediately and permanently ends the tool's access to the Google account. No copy of the credential survives revocation in any usable form.

Children

Content Clips is not directed at children and has no users other than its operator.

Changes

If this policy changes, the date at the top of this page will change with it.
